State C · long-press preview Long-press (~500 ms) on upload card → OS picker → modal with full preview + filename / size / type + Import / Cancel. Esc, tap-outside, or Cancel dismiss.

Notes

Camera button sits below the upload card on mobile (hidden on desktop). It uses a separate hidden <input type="file" accept="image/*" capture="environment"> so the OS opens the camera directly. The captured frame is delivered as a temporary file — no save step.

Long-press is detected via Pointer events on the upload card (500 ms threshold, cancelled by > 12 px movement). When the timer fires the card glows accent — a visual cue that the next pick will go through the preview modal.

Short tap remains the fast path: tap the card → OS picker → auto-import. Drag-drop also auto-imports. The preview-confirm modal is opt-in via long-press.

Modal contract: image preview via URL.createObjectURL with cleanup in useEffect. PDF falls back to a placeholder card (rasterisation pending, see CLAUDE.md). ESC, click-outside, and Cancel all dismiss without committing.
